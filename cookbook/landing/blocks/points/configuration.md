
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| entries | `PointEntry[]` | (required) | Array of list items, each with optional `term` and required `detail` |
| ordered | `boolean` | `false` | When true, renders `<ol>` and applies `lp-points--ordered` class |
| `--lp-points-mark` | CSS custom property | `"\2192"` (→) | Marker glyph for unordered lists; host-overridable |
| `--lp-points-ordinal-suffix` | CSS custom property | `"."` | Text after the number in ordered lists; host-overridable |
