
- **React/Web**: Component is defined in `packages/web/packages/landing/src/blocks/StatusPill.tsx`. Renders a `<p>` element with conditional CSS class application via `['lp-status', free === true ? 'lp-status--free' : ''].filter(Boolean).join(' ')`. Props are `children: ReactNode` and optional `free?: boolean`. Base and accent styling live in the `lp-status` / `lp-status--free` rules in `blocks.css` (see #appearance).

- **SwiftUI**: Implement as `Text` inside a pill shape. Do not clip with `.clipShape(Capsule())`, since that also clips the border stroke; instead apply `.background(Capsule().fill(backgroundColor))` and `.overlay(Capsule().stroke(borderColor, lineWidth: 1))`, switching `backgroundColor`/`borderColor` on an `isFree: Bool` parameter. Match font, letter-spacing, and uppercase casing to the source tokens (see #localization for the uppercase caveat). Use fixed fallback colors, not `--lp-*` variables, which do not exist natively: default border `rgba(216, 216, 216, 0.18)`, text `#9a9a9a`; accent border `rgba(216, 216, 216, 0.5)`, fill `rgba(216, 216, 216, 0.14)`, text `#d8d8d8`; padding `0.32rem × 0.6rem`. Use a scalable text style (for example `.caption2` with a monospaced design) so Dynamic Type applies.

- **Compose**: Implement using a `Text` composable inside a `Box` or `Surface`. Apply the pill shape via `shape = RoundedCornerShape(percent = 50)`, and switch the `background()`/`border()` colors on a Boolean `free` parameter, matching the source's default vs. accent tokens. Natively there are no `--lp-*` variables, so use the fallback values: default border `Color(0x2DD8D8D8)`, text `#9a9a9a`; accent border `Color(0x80D8D8D8)`, fill `Color(0x24D8D8D8)`, text `#d8d8d8`; padding `0.32rem × 0.6rem` (about 5dp × 10dp). Set the text size in `sp` (about `10.sp`) so system font scaling applies.

- **AppKit / UIKit**: Implement as a `UILabel` (UIKit) or `NSTextField` (AppKit) inside a small container view that draws the pill's background and border. Apply the pill shape via `layer.cornerRadius = bounds.height / 2`, and recompute it whenever the view resizes (in `layoutSubviews()` on UIKit, `layout()` on AppKit), or the radius goes stale. On AppKit, set `wantsLayer = true` first, since `layer` is nil otherwise. Switch the border/background colors on an `isFree` property, using the fallback values rather than `--lp-*` variables: default border `rgba(216, 216, 216, 0.18)`, text `#9a9a9a`; accent border `rgba(216, 216, 216, 0.5)`, fill `rgba(216, 216, 216, 0.14)`, text `#d8d8d8`. Use a text style (`preferredFont(forTextStyle:)`) so the text scales with system settings.

- **WinUI 3**: Implement as a `TextBlock` inside a `Border`. Set `CornerRadius` to half the rendered height (not a fixed value) so the shape stays a pill at any size, and update it in the `SizeChanged` handler so it does not go stale, and use `Border.Padding` — not `Margin` — to reproduce the `0.32rem × 0.6rem` padding. Switch `Background` and `BorderBrush` on a `Free` dependency property, using the fallback colors (default border `#2DD8D8D8`, text `#9A9A9A`; accent border `#80D8D8D8`, fill `#24D8D8D8`, text `#D8D8D8`) because the `--lp-*` variables do not exist natively. Use a theme text style rather than a fixed `FontSize` so system text scaling applies. Leave `HorizontalAlignment`/`VerticalAlignment` to the parent layout rather than fixing them on the pill itself.
