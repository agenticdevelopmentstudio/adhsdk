
The Site Footer is a structural footer component that renders a semantic HTML `<footer>` landmark element containing page footer content. It applies a fixed CSS class and optional custom classes, and wraps its content in a layout column (the `Wrap` component, [adhsdk.ingredient.landing.deck.wrap](cookbook:51d3b1ba-ced7-4c08-8a63-c83094d91299)) to constrain width and maintain consistency with other page sections. It is not a `Band` ([adhsdk.ingredient.landing.flow.band](cookbook:e0b59d60-0a56-4bf4-85cb-fb0e58170f8e)): unlike `Band` and `Wrap`, the footer owns its own visual chrome directly — background, text color, font size, and a top hairline border all live on `.lp-site-foot` itself. It scrolls with the page as the final element of the document (a sibling of the `Flow` container, [adhsdk.ingredient.landing.flow](cookbook:6f5f455d-b744-425d-a21e-494fc18caaf2), not a child of it), and its bottom padding includes the host's dock clearance so a fixed dock never permanently covers it.
