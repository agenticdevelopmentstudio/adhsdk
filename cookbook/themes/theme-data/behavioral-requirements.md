
### Generated shape

- **generated-header**: The first line of the file MUST be the comment `// AUTO-GENERATED by scripts/build-theme-data.mjs — do not edit.`, followed by one blank line.
- **one-export-per-sheet**: The file MUST contain exactly one `export const` for each `.css` file in `src/styles`, and no other export.
- **export-value-type**: Each export MUST be a single string literal, written with `JSON.stringify`, so line breaks, quotes and backslashes in the CSS are escaped.
- **export-name**: An export name MUST be the file name without `.css`, with each hyphen followed by a lowercase letter replaced by that letter in uppercase, plus the suffix `Css`.
- **export-name-digits**: A hyphen followed by anything other than a lowercase letter MUST be left in place by the name conversion; no shipped file name triggers this case.
- **export-order**: Exports MUST appear in ascending order of the sorted file names, so `adh-comic.css` precedes `adh.css` because the hyphen sorts before the period.
- **trailing-newline**: The file MUST end with a single newline after the last export.
- **non-theme-sheets**: The file MUST also carry the sheets that are not registered themes, because the script reads every file in the directory without a filter beyond the `.css` extension.
- **non-ascii-preserved**: Characters outside ASCII, such as the em dash in a comment, MUST be written as they are, not as `\u` escapes.

### Stylesheet content

- **relative-import-inlined**: A relative `@import` of the form `@import './x.css';` (or with double quotes, and `./` or `../`) MUST be replaced by the full text of that file, recursively, so no exported string contains a relative `@import`.
- **remote-import-kept**: A remote `@import url(...)` MUST be left in the string unchanged; 35 of the exports begin with or contain one for a web font request.
- **self-hosted-fonts-kept**: A sheet that declares `@font-face` MUST keep the declaration in its string; `adhCss`, `adhIosevkaCss`, `charcoalCss` and `fishlampCss` do.
- **shared-palette-copied**: A sheet that imports another sheet MUST carry that sheet's text inside its own string; `fishlampCss` and `mikefullertonLandingCss` each contain the full text of `fishlampPaletteCss`.
- **import-position-preserved**: The inlined text MUST sit exactly where the `@import` statement was, with the text before and after it unchanged.
- **css-otherwise-verbatim**: Apart from import inlining, the string MUST equal the file's text, with no minification or rewriting.

### Generator

- **runs-from-package-root**: The script MUST read from `src/styles` and write to `src/theme-data.ts`, both resolved against the current working directory, so it MUST be run from the themes package root.
- **overwrite-output**: The script MUST replace any existing `src/theme-data.ts` in full.
- **completion-message**: On success the script MUST print `build-theme-data: N themes → src/theme-data.ts`, using `theme` when N is 1 and `themes` otherwise.
- **self-import-error**: When a stylesheet imports itself, directly or through a chain of relative imports, the script MUST throw an error whose message is `inline-imports: <path> imports itself`.
- **missing-import-target**: When a relative `@import` names a file that does not exist, the script MUST fail with the file system's read error and MUST NOT write the output file.
- **deterministic-output**: The same set of CSS files MUST produce a byte-identical output file, because the script uses no timestamp, random value or environment input.
- **generated-in-sync**: The file on disk MUST equal what `renderThemeData` in `scripts/theme-data.mjs` renders from the current stylesheets. The test `themeDataInSync.test.ts` renders it and compares, so a stylesheet edited without regenerating fails the test suite instead of shipping stale CSS.

### Lifecycle and consumption

- **not-committed**: `src/theme-data.ts` MUST NOT be committed; the package's ignore file lists it and the `clean` script deletes it.
- **regenerated-on-install**: The package's `postinstall` script MUST run the generator, so a workspace that links the package has the file after install.
- **script-ships-with-package**: The package's `files` list MUST include `scripts/build-theme-data.mjs`, `scripts/theme-data.mjs` and `scripts/inline-imports.mjs`, because `postinstall` needs all three in a copy made by a deploy.
- **manifest-is-consumer**: The manifest MUST import 39 of the exports, one per theme key, and expose each as the `css` of its `ThemeEntry`.
- **no-other-source-consumer**: The four sheets that are not themes MUST NOT be imported by the manifest; they are reachable only by importing `theme-data` directly or by loading the `.css` file.
- **consumers-stub-in-tests**: A test that does not need the CSS SHOULD stub the module instead of importing it, because the file is generated and gitignored, so a test that imports it depends on whether the themes package has been built (the comment in `settingsTab.test.tsx` says this).

### Ordering and concurrency

Not applicable: the module is constants evaluated once at import. The generator is one sequential run that reads files one at a time and writes once; it has no shared mutable state.
