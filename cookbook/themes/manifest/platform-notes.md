
- **SwiftUI**: Start from a Swift enum with a `String` raw value that conforms to `CaseIterable` and `Identifiable`; `allCases` plays the role of `themeIds` and a computed `label` property replaces the entry. Native themes are asset catalogs or token structs rather than CSS text, so `css` becomes a palette value; there is no need for a runtime string stylesheet.
- **Compose**: Use an enum class or sealed interface of theme keys, each carrying its label and a `ColorScheme` or `Typography` set, with `entries` as the key list. Compose themes are code, so the CSS string has no counterpart; keep the identifier strings stable for persisted choices.
- **React/Web**: The source is `packages/web/packages/themes/src/manifest.ts`, which imports generated string constants from `theme-data.ts` and is re-exported from the package `index.ts`. The record is typed `Record<ThemeKey, ThemeEntry>` so the compiler checks completeness, and `Object.keys` supplies the id list. The package also exposes it as the `./manifest` subpath. Consumers are `ThemeStyle.tsx`, the adh package (`theme-keys.ts` reads `themes`; `adh-themes.ts` takes `ThemeKey` as a type only), the persona package, and tests that iterate the corpus.
- **AppKit / UIKit**: Model it as a Swift enum, as for SwiftUI, with `NSColor` or `UIColor` palettes; on macOS apply a theme through `NSAppearance` plus custom color assets, and on iOS through trait collections. No runtime stylesheet exists, so the manifest becomes an enum with a palette per case.
- **WinUI 3**: Represent each theme as a `ResourceDictionary` XAML file and register them in a C# class: `enum ThemeKey`, a `record ThemeEntry(ThemeKey Id, string Label, Uri Source)` and a `static readonly IReadOnlyDictionary<ThemeKey, ThemeEntry> Themes` built in a static initializer. Expose `ThemeIds` as an `ImmutableArray<ThemeKey>` when order matters (a plain `Dictionary` does not guarantee order). A picker binds an `ObservableCollection<ThemeEntry>` to a `ComboBox` or `GridView` and swaps the active dictionary by replacing an item in `Application.Current.Resources.MergedDictionaries`. The CSS text is replaced by `ResourceDictionary` brushes keyed per `ThemeDictionaries` (`Light`, `Dark`, `HighContrast`).
