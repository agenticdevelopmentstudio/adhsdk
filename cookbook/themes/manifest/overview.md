
The theme manifest is the single registry of the stylesheets the themes package ships. It exports the `ThemeKey` string-literal union, the `ThemeEntry` shape (`id`, `label`, `css`), the `themes` record that maps each key to its entry, and `themeIds`, the list of keys. Each entry's `css` is the stylesheet text imported from the generated `theme-data` module ([adhsdk.ingredient.themes.theme-data](cookbook:6ddafe05-a417-498d-90b1-00f69c89f7ac); its header reads "AUTO-GENERATED by scripts/build-theme-data.mjs — do not edit"). The manifest holds data only: it applies nothing to a document.

A theme is usable only once it is registered here. The comment in `rescued-themes.test.ts` states that the registry (`ThemeKey`, `themes`, `themeIds`) is the only path any consumer, including the demo site's theme picker, has to reach a theme. `ThemeStyle` ([adhsdk.ingredient.themes.theme-style](cookbook:54b48020-df78-4b41-853c-268ad0ea6b84)) reads `themes[theme]` to emit a style element, and several tests iterate `themeIds` over the real stylesheets.
