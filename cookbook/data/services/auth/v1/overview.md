
This module holds the conventions every adh client shares when it talks to the `/v1` API, in the lowest tier that holds an authenticated HTTP client. The `/v1` API is shaped after Stripe's: a collection answers a list envelope paged by an object-id cursor, a DELETE answers a tombstone, `created` and `updated` are unix seconds while every other timestamp stays an ISO string, and `include[]` folds a sub-resource into a read.

The module exports two envelope types (`V1List`, `V1Deleted`), one constant (`V1_PAGE_MAX`), and seven functions: `withV1Query`, `listAllV1`, `listAllPublicV1`, `listV1Page`, `publicJson`, `unixToIso` and `isoToUnix`. `listAllV1` and `listAllPublicV1` are the one place that walks a collection to its end; a caller that needs every row calls one of them rather than looping `starting_after` itself. `publicJson` and `listAllPublicV1` are for public paths such as `/api/v1/feature_flags`: they send no token, whoever is signed in. `@adh-sdk/auth/client` re-exports all seven. Every authenticated request goes through `authedJson` from the Authentication Client ([adhsdk.ingredient.data.services.auth.auth-client](cookbook:3ea9329e-5acc-4c43-b5ce-bb8c50570104)) recipe, so bearer-token attachment and the single refresh-and-retry on a 401 are inherited, not reimplemented here.
