
- **Semantic element**: Component MUST use the `<p>` element to maintain semantic meaning for screen readers and document structure.
- **Content accessibility**: Text content rendered as children inherits the color and typography defined by the `.aws-explanation` rule in `styles.css`, which sets its text color from the `--aws-text-muted` design token. See **Compliance** for the contrast measurement.
- **ARIA attributes**: None required; the `<p>` element needs no role, label or other ARIA attribute.
