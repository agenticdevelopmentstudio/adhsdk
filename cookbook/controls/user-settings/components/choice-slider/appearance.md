
- **Container**: A grouping element that wraps the label, slider, caption and hint. On web it carries the classes `aws-field` and `aws-field--choice-slider` (see the React/Web Platform Note).
- **Label**: When present, shown above the slider and using the platform's default label text color and size.
- **Slider**: The discrete slider control, wrapped together with the caption. Its look is the platform's native slider.
- **Caption**: Displays the selected choice's label, next to or below the slider. Its layout is set by the platform's styling, not by this recipe.
- **Hint**: Shown below the slider when present, as a paragraph of descriptive text.
