
- A fully blank or note-only entry: see **ignore-blank-entry**.
- Footer Add is disabled at 0 staged rows; an empty staged table shows the
  `DataTable` empty label.
- `busy`: see **disable-footer-add-when-busy** and **confirm-cancel-when-dirty**; Cancel/Esc remain enabled while busy.
- Cancel, Esc and backdrop click, dirty or clean: see **confirm-cancel-when-dirty**.
- State resets on close (staged rows, selection, and entry fields), so
  reopening starts with an empty entry row and table.
