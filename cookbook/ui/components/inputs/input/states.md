
| State | Appearance change |
|-------|------------------|
| default | Border: `apt-border`, background: `apt-bg`, text: `apt-text` |
| focus | On `focus-visible`:  Border: `apt-gold`; 2px `apt-gold/25` outer ring around the field for depth |
| disabled | Opacity reduced to 50%, cursor becomes "not-allowed", pointer events disabled |
| invalid | On `aria-invalid`: border: `apt-red`; 2px `apt-red/25` outer ring around the field |
| placeholder | When text is absent:  Text color: `apt-text-dim` for reduced visual weight |
