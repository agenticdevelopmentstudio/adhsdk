
| State | Appearance change |
|-------|------------------|
| Default | Border: `apt-border`, background: `apt-bg`, text: `apt-text` |
| Focus (focus-visible) | Border: `apt-gold`; 2px `apt-gold/25` outer ring around the field for depth |
