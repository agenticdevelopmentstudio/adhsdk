
PanelStack is a container component that renders multiple DetailPane components based on a set of visible topic indexes. It serves as a layout wrapper for displaying detail views in a multi-pane interface. The component forwards a ref to its root div element to allow parent components to interact with the container directly. The `topics` array element type, `TopicData`, is the Topic data model defined by [adhsdk.ingredient.chat.modes.three-pane.detail-pane](cookbook:292f17e2-1df8-4126-a26c-4160e8e88708) — see `depends-on`.
