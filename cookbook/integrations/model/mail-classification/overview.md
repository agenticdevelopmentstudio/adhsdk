
MailClassification answers one question for the Gmail integration: where does a message sit, for the purposes of deciding whether to mirror it. It has two public types in one file. `MailClass` is a four-case enum (`filed`, `archived`, `spam`, `trash`). `MailClassifier` is a caseless enum namespace whose single operation, `classify(labelIds:)`, maps a list of Gmail label id strings to one `MailClass`. It is a pure function with no I/O. Callers use it in two places: the Gmail message parser classifies each fetched message, and the `EmailMessage` record classifies itself when it is built without an explicit class. A connection's `MailSyncSettings.allows(_:)` then decides, per class, whether the message is kept. The source's own comment on the Gmail query builder says the query only narrows the fetch and that `MailClassifier` stays the authority on what is mirrored.
