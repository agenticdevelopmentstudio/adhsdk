
- **SwiftUI**: Source platform is Swift: `packages/apple/AgenticDeveloperHubSDK/Integrations/Service/MailCommandSupport.swift`. It uses `Foundation` only: `JSONEncoder` with `.prettyPrinted` and `.sortedKeys`, `Calendar(identifier: .gregorian)` pinned to UTC, and `ISO8601DateFormatter` with two option sets. There are no tests beside it. Both enums are internal to the SDK module, so a SwiftUI host reaches them only through `MailCommandLine` and `MailToolSource`.
- **Compose**: Kotlin has no pretty printer with sorted keys by default; use `kotlinx.serialization` `Json { prettyPrint = true }` and sort map keys before encoding (or encode to a `JsonObject` built with a `TreeMap`). For dates, use `java.time.LocalDate.parse` in strict mode, then `atStartOfDay(ZoneOffset.UTC)` or `atTime(LocalTime.of(23, 59, 59, 999_000_000))`, and `OffsetDateTime.parse(...).withOffsetSameInstant(ZoneOffset.UTC)` formatted with a fixed pattern for the timestamp form. `LocalDate.parse` rejects 30 February without a manual round-trip check.
- **React/Web**: Use `JSON.stringify(value, sortedReplacer, 2)` with a replacer that rebuilds objects with sorted keys (note that `JSON.stringify` does not escape `/`, a difference from the Swift output). For dates, match `^\d{4}-\d{2}-\d{2}$` with ASCII digit classes, build `new Date(Date.UTC(y, m - 1, d))` and compare the year, month and day it reports; for a timestamp require a zone designator and call `toISOString()`, which already gives the milliseconds-and-Z form.
- **AppKit / UIKit**: Same Swift source as above; it compiles unchanged on macOS and iOS because it uses only `Foundation`. Output goes to a terminal for the CLI and to an MCP tool result, never to a view.
- **WinUI 3**: Write a static class `MailJson` and a static class `MailDateBound` in C#. For JSON, use `System.Text.Json.JsonSerializer.Serialize` with `JsonSerializerOptions { WriteIndented = true }`; `System.Text.Json` does not sort object keys, so serialize through a `JsonNode` tree and re-add properties in ordinal order, or sort dictionaries first, and set `Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping` if you want to match the unescaped forms you choose for `/`. For bounds, use `DateOnly.TryParseExact(text, "yyyy-MM-dd", CultureInfo.InvariantCulture, DateTimeStyles.None, out var date)` after the same shape check (it also rejects 30 February), then `date.ToDateTime(TimeOnly.MinValue, DateTimeKind.Utc)` or `new TimeOnly(23, 59, 59, 999)`; for a timestamp use `DateTimeOffset.TryParse` with `DateTimeStyles.RoundtripKind` after confirming a zone designator is present, then `ToUniversalTime().ToString("yyyy-MM-dd'T'HH:mm:ss.fff'Z'", CultureInfo.InvariantCulture)`. Return `string?` and keep rejection as null rather than an exception. These are pure static helpers, so no `ObservableCollection` or `INotifyPropertyChanged` is involved.
