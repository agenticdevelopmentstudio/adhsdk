
| State | Appearance change |
|-------|------------------|
| Default | All controls rendered; colors from applied theme |
| Help button hidden | Help button and adjacent space removed; other controls unchanged |
| Import button hidden | Import button and adjacent space removed; other controls unchanged |
| Fewer than 2 modes (single item, or no modes available) | Mode control hidden via the fewer-than-2 rule and spacing removed; buttons remain visible. With no modes, the control is built with zero segments and the selected segment is set to no-segment (iOS `UISegmentedControl.noSegment`) / -1 (macOS) |
