
`UserDefaultsThemeStorage` is the `ThemeStorage` ([adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.theme-storage](cookbook:62abe97d-75f7-48c0-83cd-6df02a48515e)) implementation for a host that has no settings system of its own. `ThemeStorage` is a `@MainActor`, class-bound protocol with three members: `customThemes` (an array of `ColorTheme`), `activeThemeID` (an optional `String`) and `onExternalChange` (an optional closure). This class keeps the first two in a `UserDefaults` domain and uses `UserDefaults.didChangeNotification` to fire the third when something other than this object moved them.

The source comment gives the reason it exists: a host with a settings system supplies its own `ThemeStorage` instead of inheriting a preference location, and plenty of hosts (a single-window utility, an iOS app whose only preference is the theme) have none, so the same short implementation lives here once. The keys and the JSON encoding match what the AgenticDeveloperHubSDK host writes through its own settings system, so a host that later swaps this class for its own conformer finds the saved themes where this class left them.

Built-in themes are never stored here; the `ThemeStorage` comment states that `ThemeStore` ([adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.theme-store](cookbook:d15bba09-4574-4fd1-93a0-f7d2cccd04f2)) concatenates them at read time, so an empty storage still yields a full catalog. The model type it stores is described by [adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.color-theme](cookbook:932449c9-b57f-4e2c-992a-1e27584742b6).
