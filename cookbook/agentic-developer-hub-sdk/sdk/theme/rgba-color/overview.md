
`RGBAColor` is a platform-neutral color value with four `Double` components (`red`, `green`, `blue`, `alpha`) held in the range 0 to 1. It exists so theme and settings data can be stored without a dependency on `NSColor` or `UIColor`: it encodes as the string `"#RRGGBBAA"`, which round-trips through `UserDefaults`. UI layers add the platform-color bridge. It is the color type of `ColorTheme` ([adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.color-theme](cookbook:932449c9-b57f-4e2c-992a-1e27584742b6)), `SemanticPalette` ([adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.semantic-palette](cookbook:1f80f43d-5aa4-42cf-bc3e-fb742662b615)) and `ITermColorsParser` ([adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.i-term-colors-parser](cookbook:231a7e9a-8c03-44b3-afaf-b71755e05c1d)). It is a pure value type with no I/O and no state.

The source file also defines three constants (`black`, `white`, `clear`). Luminance, blending and compositing helpers live in a separate extension file (`RGBAColor+Theme.swift` ([adhsdk.ingredient.agentic-developer-hub-sdk.sdk.theme.rgba-color-theme](cookbook:591d0b87-ce71-4b11-8642-149fc405cce9))) and belong to the theme layer, not to this contract.
