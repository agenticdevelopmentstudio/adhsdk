
`LayeredSettingsStore` is a `SettingsStore` whose values can be overridden in a narrower scope (one browser pane, say) while everything it does not override reads through to a broader `SettingsStore`, its `fallback`. Reads answer the override when one exists and the fallback otherwise. Writes always land in the overrides, so the broader store is never touched from here for a non-secure key. Secure keys skip the layering entirely and go straight to the fallback: a secret has one home, and a per-pane copy would be a second place to leak it from. The store's `changes` publisher reports override changes plus fallback changes for keys the overrides do not hold, so a pane never sees a global change it is hiding. The class is `@MainActor` and is built on the `SettingsStore` base class, two private providers (one layered, one secure forwarder) and a private by-name key type.
