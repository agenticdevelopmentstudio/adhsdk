
- **SwiftUI**: The source file `Core/Routing/RouteResponse.swift` imports only `Foundation` and is UI-independent, so a SwiftUI host uses it unchanged. It is a `public struct` that is `Sendable` and `Equatable`. The encoder is `JSONEncoder` with `keyEncodingStrategy = .convertToSnakeCase`, `dateEncodingStrategy = .iso8601` and `outputFormatting = [.prettyPrinted, .sortedKeys]`; the private `ErrorBody` struct carries the `error` key.
- **Compose**: A Kotlin `data class RouteResponse` (override `equals` for the `ByteArray` body). Use kotlinx.serialization `Json` with `prettyPrint = true` and a naming strategy of snake case (`JsonNamingStrategy.SnakeCase`), and format dates as ISO-8601 strings with `Instant.toString()` truncated to seconds. Note that kotlinx.serialization's key order is declaration order, not sorted, so sort keys explicitly to match the bytes, and its pretty printer writes `"key": value` rather than `"key" : value`.
- **React/Web**: A readonly object type with `Uint8Array` or string body. Build with `JSON.stringify(value, replacer, 2)`, snake-casing keys and sorting them in the replacer and converting `Date` to an ISO string without milliseconds; `JSON.stringify` writes `"key": value` (no space before the colon), so byte equality with the Swift output needs a custom formatter. Build the error body from an object, never string concatenation.
- **AppKit / UIKit**: Identical to the SwiftUI note: the file is UI-framework-agnostic and only the embedding application differs, never this contract.
- **WinUI 3**: A C# `record RouteResponse` with `byte[]` body (supply a custom `Equals` for the array). Use `System.Text.Json` with `JsonNamingPolicy.SnakeCaseLower` (.NET 8 and later), `WriteIndented = true` and a custom ordering of properties, since `System.Text.Json` writes properties in declaration order and indents with two spaces but writes `"key": value`. In ASP.NET Core minimal APIs, `Results.Json` or a custom `IResult` writes this status, body and headers; share one configured `JsonSerializerOptions` (it is safe to share once frozen, unlike the Swift encoder note).
