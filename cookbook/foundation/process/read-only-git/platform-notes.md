
- **SwiftUI**: The source is `packages/apple/AgenticDeveloperHubSDK/Core/Process/ReadOnlyGit.swift` in the `AgenticDeveloperHubSDKCore` target, Foundation only. It builds a `Foundation.Process` for `/usr/bin/env`, sets `Process.environment`, and runs it through `CommandRunner.runToCompletion` with an empty `Data()` as input and a 5-second timeout. A repository test (`GitProcessBottleneckTests`) allowlists this file, beside `Core/Git/`, as the spawn point for the hook and status-line path; it fails on any other file that spells a git command line. It has no SwiftUI content.
- **Compose**: Use `ProcessBuilder("git", ...)` with `environment()["GIT_OPTIONAL_LOCKS"] = "0"` and the PATH repair applied to `environment()["PATH"]`; `redirectInput` from `/dev/null` or close the stream, drain stdout on a coroutine (`Dispatchers.IO`), and use `waitFor(5, TimeUnit.SECONDS)` then `destroyForcibly()`. Android rarely has `git`; this belongs on the JVM desktop.
- **React/Web**: Node: `child_process.execFile('git', args, { env, timeout: 5000, maxBuffer })` with `env.GIT_OPTIONAL_LOCKS = '0'`, catching the error and returning the empty string; set `stdio: ['ignore', 'pipe', 'pipe']` for the closed stdin. A browser cannot run `git`.
- **AppKit / UIKit**: The same `Process` code runs on macOS. iOS cannot spawn `git`, so this does not port to UIKit.
- **WinUI 3**: Use `System.Diagnostics.Process` with `ProcessStartInfo { FileName = "git", ArgumentList = {...}, UseShellExecute = false, RedirectStandardOutput = true, RedirectStandardError = true, RedirectStandardInput = true, CreateNoWindow = true }`. Set `psi.Environment["GIT_OPTIONAL_LOCKS"] = "0"`. Drop the `/usr/bin/env` launcher, because `UseShellExecute = false` resolves `git.exe` on `PATH`. Replace the Unix directory repair with the common install directories (for example `C:\Program Files\Git\cmd`) appended when missing, and join with `;` (`Path.PathSeparator`). Close standard input right after `Start()` (`StandardInput.Close()`). Drain standard output with `StandardOutput.ReadToEndAsync()` while waiting (`Process.WaitForExitAsync` with a `CancellationTokenSource` of 5 seconds), and call `Kill(entireProcessTree: true)` on timeout. Decode strictly with `new UTF8Encoding(false, throwOnInvalidBytes: true)` and return `""` on failure. Call it from a background `Task`, never from the UI thread.
