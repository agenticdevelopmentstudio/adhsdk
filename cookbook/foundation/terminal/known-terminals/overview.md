
This is the one list of terminal applications the toolkit knows how to enumerate, match by the `$TERM_PROGRAM` environment value and bring to the front. `KnownTerminal` is one entry: a human-readable `displayName`, the macOS `bundleID` used to find a running instance, and the `termProgramValues` that identify it. `KnownTerminals.all` is the default catalog (iTerm2, Terminal.app, Warp and VS Code), and `KnownTerminals.match(termProgram:in:)` finds the entry whose values contain a given `TERM_PROGRAM`. Three callers read it: the window-activation tester lists every terminal in its inventory, the bring-terminal-to-front strategy matches a session's `TERM_PROGRAM` to a bundle id and activates the app, and the conversation summary names a session's terminal. This code holds a value type, a constant list and one lookup; running-app lookup and activation live in the window-activation code, outside these sources.
