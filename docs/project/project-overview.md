## Project Summary

`adhsdk` is a set of reusable per-platform packages for agentic apps: the shared web libraries (`ui`, `chat`, `themes`, `markdown`, `search`, `editing`, …) beside the adh app platform and its feature packages; a workspace of Xcode projects for Apple (the multi-platform `AgenticDeveloperHubSDK` frameworks, the macOS-first `AgenticDeveloperHubSDK` product frameworks, the `AgenticDeveloperHubSDKApp` host and the `AIPlugins` bundles); and a Python package for Terminal. It absorbed the former `adhsdk` repo, history included.

## Type & Tech Stack

- **Type:** multi-platform library toolkit
- **Web:** TypeScript + React 19 + Tailwind v4, one pnpm workspace at `packages/web/`
- **Apple:** Swift 6.3, Xcode projects generated by XcodeGen from `project.yml`, wired by `packages/apple/AgenticDeveloperHubSDK.xcworkspace`
- **Terminal:** Python (`packages/terminal/pyproject.toml`)
- **Android / Windows:** port plans in `docs/planning/ports/`

## Key Files & Components

- `install.sh` — regenerates every Xcode project, then installs and builds the web workspace
- `packages/web/packages/chat/` — chat UI and `PersonaChatBackend`
- `packages/web/packages/persona/` — the consumer crossing for the persona vocabulary
- `packages/apple/AgenticDeveloperHubSDK/` — multi-platform core, UI and theme model
- `packages/apple/AgenticDeveloperHubSDK/project.yml` — the product frameworks and their aggregate targets
- `packages/apple/AIPlugins/` — `.aiplugin` bundles that link the toolkit frameworks without embedding them
- `tools/` — `check_doc_links.py`, `check_boundaries.py` and the other guards CI runs

`docs/planning/planning.md` (milestones), `docs/planning/merge-adhsdk.md` (the merge), `docs/planning/ports/`, and point-in-time records under `docs/archive/`.

Also: [`docs/architecture/session-daemon-core.md`](../architecture/session-daemon-core.md) (the `Database/Daemon/` tier shared by Stenographer's and the Kitchen's daemons; written and committed, not yet built or tested).

New directories from that move, all inside `packages/apple/AgenticDeveloperHubSDK`:

- `Database/Daemon/` in `AgenticDeveloperHubSDKDatabase`: `Core/`, `Ingestion/`, `Sessions/`, `Transcripts/`, `Oversight/`, `AILog/`, `Preferences/`, `Routes/`, `Settings/`. macOS only (a `destinationFilters: [macOS]` source path, and every file wrapped in `#if canImport(AgenticDeveloperHubSDKCore)`).
- `AgenticDeveloperHubSDKDatabase` now depends on `AgenticDeveloperHubSDKCore` and `AIPluginKit`, on macOS only. **Invariant: `AIPluginKit` (and `AgenticDeveloperHubSDKCore`) never import `AgenticDeveloperHubSDKDatabase`.**
- `Core/Sessions/`, `Core/Routing/`, `Core/ClaudeHooks/`, `Core/Process/ReadOnlyGit.swift` and `Core/Stenographer/ADKDIdentifiers.swift` in `AgenticDeveloperHubSDKCore`; the launchd pieces in `AgenticDeveloperHubSDKLaunch`.
- The toolkit and DaemonKit stay independent of each other; each daemon bridges the two.

## Build & Test Commands

```bash
./install.sh
cd packages/web && pnpm build && pnpm test && pnpm lint
cd packages/terminal && pip install -e . && pytest
xcodebuild -workspace packages/apple/AgenticDeveloperHubSDK.xcworkspace \
  -scheme AgenticDeveloperHubSDKMacOSTestsAll -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ~/Library/Developer/Xcode/DerivedData/adhsdk-managed \
  -skipPackagePluginValidation -skipMacroValidation build
```
